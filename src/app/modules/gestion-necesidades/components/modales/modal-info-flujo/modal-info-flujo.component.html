Flujo de Gestión de Necesidades

El proceso de gestión de necesidades docentes sigue un flujo estructurado por roles.

Usa las flechas para navegar entre las etapas
Paso 1 de 3

Coordinador

Identifica y crea las necesidades docentes del programa académico para el periodo correspondiente.

Responsabilidades:
  • Analiza la carga académica del programa
  • Identifica asignaturas sin docente asignado
  • Registra las necesidades en el sistema
  • Envía las necesidades al siguiente nivel
Paso 2 de 3

Secretario

Revisa, valida y consolida todas las necesidades reportadas por los coordinadores de programa.

Responsabilidades:
  • Verifica la información de cada necesidad
  • Valida requisitos y disponibilidad presupuestal
  • Consolida el listado completo de necesidades
  • Envía para aprobación final
Paso 3 de 3

Jefe

Aprueba las necesidades validadas y realiza las asignaciones de docentes correspondientes.

Responsabilidades:
  • Revisa el consolidado de necesidades
  • Aprueba o rechaza según disponibilidad
  • Asigna docentes a las necesidades aprobadas
  • Finaliza el proceso de gestión
